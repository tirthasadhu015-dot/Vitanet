Vitanet - UI/UX & Design System (design.md)
1. Brand Identity & Design Philosophy
Brand Name: Vitanet

Tagline: Decentralized Trust for Life-Saving Organ Donations

Design Philosophy: Clean, clinical, trustworthy, and modern. Because Vitanet deals with critical medical operations and financial escrow, the interface must prioritize high legibility, clear status indicators, and minimal cognitive load for patients, donors, and hospital administrators.

2. Color Palette
Primary / Trust: Deep Medical Blue (#0F172A / #1E3A8A) — Represents security, professionalism, and reliability.

Secondary / Action: Teal / Cyan (#06B6D4 / #0D9488) — Used for primary buttons, active links, and interactive elements.

Accent / Crypto & Status: Solana Purple / Vibrant Green (#10B981 for Success/Completed, #F59E0B for Pending Escrow).

Neutrals:

Background: Pure White (#FFFFFF) / Off-White Slate (#F8FAFC)

Text Primary: Charcoal Dark (#1E293B)

Text Secondary: Slate Gray (#64748B)

3. Typography
Font Family: Inter or Plus Jakarta Sans (Clean, modern sans-serif fonts optimized for screen readability).

Hierarchy:

H1 (Page Titles): 32px / Bold (font-weight: 700)

H2 (Section Headings): 24px / Semi-Bold (font-weight: 600)

H3 (Card Titles): 18px / Medium (font-weight: 500)

Body Text: 14px or 16px / Regular (font-weight: 400) with line-height: 1.5

4. UI Layout & Component Structure
4.1 Navigation Bar (Navbar)
Left: Vitanet Logo + Brand Name with a medical cross / blockchain node icon.

Center Links: Home, Find Organ, Hospitals Directory, About Us.

Right Actions: Connect Solana Wallet button (showing truncated address if connected) and Role-based Dashboard link.

4.2 Forms & Input Fields (Registration Pages)
Style: Floating labels or clear top-aligned labels with rounded corners (border-radius: 8px).

File Uploads: Drag-and-drop file upload zones for Donor Health Certificates with file name preview and size validation.

Validation States: Inline validation feedback with clear error messaging in red (#EF4444) and success indicators in green (#10B981).

4.3 Dashboards (Hospital, Patient, & Donor Views)
Layout: Sidebar navigation + Main content area with a card-based grid system.

Data Tables: Clean tabular layouts with alternating row colors, badge pills for status indicators (Pending, Hospital Verified, Completed), and pagination controls.

5. Accessibility & Responsiveness
Mobile-First Design: Fully responsive layout ensuring seamless use across smartphones used by patients/donors and desktop dashboards used by hospital staff.

Color Contrast: High contrast text ratios adhering to WCAG AA standards for medical clarity.
